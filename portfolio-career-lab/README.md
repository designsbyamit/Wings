# Portfolio Career Lab

Workshop system for turning career evidence into strengths, interests, market signals, a growth sweet spot, and a practical roadmap.

## Journey
1. Career Data Playground (pre-work)
2. Pick Your Fighter
3. Portfolio Mythbusters
4. Find Your Strengths
5. Four Pursuits
6. Ruchi Radar
7. Disha Guardrail
8. Growth Sweet Spot
9. Future Self Blueprint
10. Portfolio Reframe

## App
The web app starts with Career Data Playground. It accepts structured and unstructured inputs, normalises them into a standard career dataset, generates exploratory visualisations, and exports an Excel-compatible workbook.

## Separation
This project is isolated under `portfolio-career-lab/`. It does not modify WingSpan.
